
# Yasitha | Personal Portfolio Website

## 🇬🇧 English

### About the Project
This is my personal portfolio website, created to showcase my skills, projects, and learning journey as an aspiring Web Developer and IT Engineer.

The website introduces my background, technical skills, projects, and contact information through a clean and professional design.

### Features
- Home section with a personal introduction
- About Me section
- Technical skills showcase
- Projects portfolio
- Contact section with GitHub link
- Responsive and user-friendly layout

### Technologies Used
- HTML5
- CSS3
- JavaScript (for future enhancements)
- Font Awesome 6

### Project Structure
```text
portfolio/
├── index.html
├── style.css
├── myphoto.jpg
├── project1.png
├── project2.png
└── README.md
```

### How to Run
1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `index.html` in your web browser.

### Purpose
This project helps me practice web development, improve my programming skills, and prepare for my future career as an IT Engineer.
